Kazuma 的 DSH 插件

四个可独立安装的 DeepSeek Harness（DSH）组合包。 纯 JavaScript、无第三方依赖、不调用模型、不上传任何数据；会话迁移只在本机复制和移动会话日志。

插件

Token 用量统计 · Token usage

在左侧栏新增「Token 用量」：按对话与项目汇总 token 用量，带趋势图和会话明细。全局总量只对原始消费事件汇总一次；父子项目的汇总行不能相加。只读、仅回环地址、无写入接口。

目录 dsh-token-usage/ · 需要 DSH >=0.2.0-0 <0.3.0

对话记事本 · Conversation notebook

在对话右侧栏为每个对话提供一份独立的纯文本笔记，输入即保存到本机磁盘；归档、重启或清除浏览器数据都不会删除。经已认证路由读写，不读对话正文、不调用模型。

目录 conversation-notebook/ · 需要 DSH >=0.2.0-0 <0.3.0

界面微调 · DSH tweaks

一批 DSH 界面小改动：在插件详情页的动作区加「打开所在文件夹」，点一下就在系统文件管理器里定位插件的安装目录；在会话行菜单里加「标为未读」，让读过但暂时没空处理的会话保留行尾提醒。只按包名解析本机目录、不经过 shell；未读标记只保存在浏览器本地。

目录 dsh-tweaks/ · 需要 DSH >=0.2.0-0 <0.3.0

会话迁移 · Workspace session migration

把对话完整迁移到另一个工作区：复制全部事件到目标工作区的新会话，再把原会话移入备份区或归档。只在本机读写会话日志，不调用模型、不联网。

目录 workspace-session-migration/ · 需要 DSH >=0.2.2-rc.5 <0.3.0

安装

克隆仓库后，在 DSH 的「插件 → 添加插件」里选择对应子目录即可：

git clone https://github.com/Kazuma-124/Personal_DSH_Plugins.git
  • Personal_DSH_Plugins/dsh-token-usage
  • Personal_DSH_Plugins/conversation-notebook
  • Personal_DSH_Plugins/dsh-tweaks
  • Personal_DSH_Plugins/workspace-session-migration

也可以在 DSH 的「插件 → 发现」里添加本仓库的插件索引，直接浏览和安装：

https://cdn.jsdelivr.net/gh/Kazuma-124/Personal_DSH_Plugins@main/docs/index.json
