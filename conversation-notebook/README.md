# 对话记事本

在对话右侧栏打开入口页（加号），选择“对话记事本”。每个对话有一份独立的纯文本笔记，新笔记从空白开始，只由用户手动编辑。每次输入同步写入本设备当前浏览器的持久存储；关闭侧栏、刷新页面或重启后，在同一浏览器来源打开同一对话即可继续编辑。Desktop 使用稳定的 `dsh-app://app` 来源，因此数据可跨启动保留。

笔记不读取对话正文，不调用模型，不注入模型上下文，不提供代理读写工具，不访问工作区文件。保存失败会保留当前页面中的草稿并提示重试；读取失败时禁止编辑，避免覆盖原有内容。

数据按对话 ID 保存在本插件独有的 localStorage 命名空间中，独立于侧栏布局。存储仅限本设备当前浏览器；清除浏览器数据会丢失笔记，切换浏览器或改变应用来源地址也无法访问原笔记。同键的多个标签或窗口采用最后写入优先；即使编辑器正在聚焦，输入内容也可能被其他标签的写入覆盖。保存失败的本地草稿在当前页面中暂时受到保护，仍须重试保存。卸载只移除本插件注册的入口、正文、标题、事件监听以及当前已被侧栏服务采用的本插件标签，不删除笔记，也不关闭其他插件标签。当前侧栏 closeIn 对未被此窗口采用的历史对话布局不执行清理；本插件不直接修改其他组件的布局存储。

## 使用

1. 打开任意对话的右侧栏，在入口页（加号）选择“对话记事本”。
2. 在空白笔记中直接输入，修改会即时保存；底部显示当前状态。
3. 再次打开同一对话时继续编辑；切换到其他对话则是另一份独立笔记。

## 检查与限制

- 构建与测试：`node build.mjs`、`node --test tests/*.test.mjs`。运行时产物全部位于 `dist/`，无包依赖、外部资源或源码目录路径。
- 部署：仓库根的 `node scripts/deploy.mjs` 会把本目录（含重新构建的 `dist/`）同步到当前 profile 的默认插件目录；首次安装后在 DSH「插件」页选择该目录即可。
- 已在运行的页面中确认入口页卡片、正文与标题槽位注册为 active；正文的实际外观、浅色/深色主题、刷新后的持久化仍需在浏览器中人工确认。
- 图标为本包原创 SVG。
