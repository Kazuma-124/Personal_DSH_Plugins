# 版本记录

版本号遵循 SemVer；每个版本对应一次提交，`docs/index.json` 保留各版本的固定 commit 与发布时间。

## 2.0.0 — 2026-11-23

- 包名与目录从 `dsh-plugin-actions` 改为 `dsh-tweaks`，patch 行 id 改为 `<包名>:tweaks`，Host 路由改为 `/api/tweaks/reveal`；包名变化意味着需要卸载旧插件后重新安装。
- 插件定位改为「DSH 界面小改动合集」：原有「打开所在文件夹」和「标为未读」保持不变，后续同类小功能加入本包。
- 未读标记的浏览器存储键改为 `dsh.tweaks.unread.v1`，首次加载时迁移旧键 `dsh.plugin-actions.unread.v1` 的数据。
- 更换为表示「微调」的滑块图标，更新中英文标题与说明。

## 1.1.0 — 2026-11-23

- 新增会话「标为未读」：会话行菜单可标记和取消标记，侧栏行尾显示未读圆点；会话进入主视图或归档时自动清除，重启后仍打开的会话保留标记。标记保存在浏览器本地存储。
- 客户端新增 `sidebar.session.row.trailing` 行尾标记和带原创图标的会话右键菜单贡献（`contextMenu.icon`），并把用到的客户端包补进 `dsh.client.inject`。
- 更新插件说明与 locale 文案，说明本包同时提供两类界面小改动。

## 1.0.1 — 2026-11-23

- 同步发布元数据与文档；运行时代码未变。

## 1.0.0 — 2026-11-21

- 首个公开版本：在每个插件的详情页动作区增加「打开所在文件夹」。
- 按包名解析本机安装目录，交给系统文件管理器打开；不读取文件内容、不经过 shell。
