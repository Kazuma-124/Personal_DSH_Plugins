# Compaction prompts

在 DSH 的 **设置 → 压缩提示词** 中，为所有会话选择一个压缩提示词。列表使用单选按钮，选择后自动保存，下一次压缩生效。正在进行的压缩保留开始时读取的提示词。

## 为什么需要

DSH 内置的上下文压缩指令是固定的：压缩时由模型把较早的对话压成结构化检查点。不同项目对检查点的结构、语言和重点要求不同，而 DSH 没有提供修改入口。本插件把这份指令做成可选项：

- 可以继续跟随官方实现，不改变默认行为；
- 可以在 DSH 升级后保留旧版官方指令，避免新版本改变压缩结构；
- 可以粘贴自己的模板，并随 DSH 版本一起管理。

选择对所有会话生效，保存在本机数据目录，不写入会话日志。

## 提示词来源

- **DSH 官方 · 跟随当前版本**：直接使用当前安装的官方压缩实现，随 DSH 升级。
- **官方快照**：固定使用某份官方提示词；升级后仍保留选择的历史内容。历史快照收在可折叠列表中，减少列表占用；可逐项删除，当前安装版本对应的快照除外。
- **自定义**：在页面粘贴添加，或首次启动时从旧 `active/` 与 `presets/` 目录导入的提示词。可随时编辑名称与正文，或删除；官方项只读。

点击 **添加自定义提示词**，填写名称并粘贴全文，保存后会加入列表；再单选该项启用。自定义正文最多 64 KiB，相同名称与正文不会重复添加。

每项都可以展开查看全文。**刷新列表**读取已保存的全局选择；页面获得焦点或每隔 15 秒会自动刷新。**同步当前官方版本**将当前进程使用的官方指令重新同步到列表。

## 官方更新

插件启动时从当前安装的 `BasicCompactionEngine.summarize()` 捕获官方指令，不调用真实模型、不发送网络请求。内容由 SHA-256 标识：首次同步保存快照，内容变化新增快照，相同内容不重复创建。历史快照不被覆盖，用户选择不被改变。同一内容在多个 DSH 版本中使用时，共用首次归档的快照。

DSH 升级并重启后自动同步新的官方提示词。当前进程中的“同步”按钮不会下载或安装新版 DSH。如果新版 DSH 改变了压缩接口，页面会显示不可用状态，禁止切换，需要适配插件。

## 存储与迁移

默认数据根目录为用户主目录下的 `.dsh/compaction-prompts`，可通过环境变量 `DSH_COMPACTION_PROMPTS_DIR` 覆盖。`catalog.json` 保存提示词内容、历史和唯一 `selectedId`；同一数据目录中的所有会话共用这个选择。

首次创建目录清单时，自动导入旧 `active/` 和 `presets/` 中有效的 `.md` / `.txt` 文件（UTF-8，非空，最多 64 KiB）。若旧 `active/` 有有效文件，保留按文件名排序的第一项为当前选择；否则默认跟随官方。原始文件保留备份，之后移动或修改它们不会影响清单。

2.0.0 起不再使用移动文件切换，`DSH_COMPACTION_PROMPTS_STRICT` 不再控制运行模式。已保存的自定义选择无法读取或清单损坏时，当前压缩报错，不会静默改选其他提示词。

## Agent 工具

`compaction_prompt` 与设置页面共享操作：`action` 为 `list`、`select`、`sync`、`add`、`update` 或 `delete`；`select`、`update`、`delete` 使用 `list` 返回的提示词 `id`；`add` 和 `update` 使用 `name` 与 `text`。编辑保留原创建时间；正文或名称变化后会生成新的内容标识，若该提示词正被使用，选择会跟随新内容。删除正在使用的自定义提示词或官方快照时，选择改为跟随官方。官方当前项与当前安装版本对应的快照不能删除；其余历史快照可以删除。选择是全局更改，影响后续压缩。

## 安装与升级

要求 DSH 0.2.2-rc.5 或更高的 0.2.x 版本，已验证 0.2.2-rc.5。按目录安装：

```sh
dsh plugin --profile <profile> add ./Personal_DSH_Plugins/dsh-compaction-prompts
```

或在 **插件 → 添加插件** 里选中 `dsh-compaction-prompts/` 目录，或添加本仓库的插件索引后在「发现」页安装。更新 Host、Client 或包声明后重启 DSH，再进入设置页。运行需要官方 BasicCompactionEngine；使用其他压缩引擎的预设不会应用此提示词。

本插件只替换官方压缩请求末尾的摘要指令；保留系统提示词、对话前缀、工具和官方的压缩提交策略。自定义提示词与选中的官方快照会交给 DSH 原有模型路由执行压缩。由于预设隔离压缩服务，插件替换共享后端类的 `summarize()` 钩子；禁用后恢复原实现。

当前版本 `2.2.0`，各版本变化见 [CHANGELOG.md](CHANGELOG.md)。

测试：`node --test tests/*.test.mjs`。清单与客户端测试可用普通 Node；后端集成测试需要打包 DSH 的 Electron Node 运行环境，并设置 `ELECTRON_RUN_AS_NODE=1` 与 `DSH_INSTALL_DIR`。
