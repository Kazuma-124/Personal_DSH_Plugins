# 版本记录

版本号遵循 SemVer；每个版本对应一次提交，`docs/index.json` 保留各版本的固定 commit 与发布时间。

## 2.2.0 — 2026-11-26

- 官方历史快照收进可折叠列表；被选中的快照仍显示在主列表，折叠时不会隐藏当前选择。
- 官方历史快照可以逐项删除，删除正在使用的快照时选择改为跟随官方。
- “跟随当前版本”选项与当前安装版本对应的快照保持不可删除。

## 2.1.0 — 2026-11-26

- 设置页与 `compaction_prompt` 工具支持编辑、删除自定义提示词；官方当前项与历史快照保持只读。
- 编辑保留创建时间；内容变化生成新的内容标识，正在使用时选择跟随更新；与其他提示词内容重复时拒绝保存。
- 删除正在使用的自定义提示词时，选择改为跟随官方版本，并在页面提示。

## 2.0.2 — 2026-11-26

- 修复设置接口的 `GET` 请求返回空 400 的问题：流式请求体模式会让 HTTP 桥为无正文的 `GET` 构造带正文请求而抛错，改为缓冲模式，并在读取前按 `Content-Length` 拒绝超过 400 KiB 的请求。
- 新增真实 HTTP 链路测试：经过认证的 `GET`、`POST`、超大正文与无效 JSON 均由实际 Web 服务返回预期状态。

## 2.0.1 — 2026-11-26

- 显式等待 Connection 服务就绪后注册设置接口，避免启动时跳过注册导致页面请求返回 404。
- 设置页面区分接口缺失和无效响应，显示 HTTP 状态与可重试提示，避免将纯文本错误直接显示为 JSON 解析异常。

## 2.0.0 — 2026-11-26

- 新增设置中的“压缩提示词”页面：全局单选、自动保存、全文预览与当前状态提示。
- 存储改为 `catalog.json`；首次自动导入旧 active/presets 文件并保留原文件，之后不再通过移动文件切换。
- 新增跟随当前 DSH 的官方选项，以及按内容去重、保留历史的官方提示词快照；启动和手动同步均保留用户选择。
- 新增共享设置操作的 `compaction_prompt` 工具，支持 list/select/sync/add；页面支持粘贴新增自定义提示词。
- 清单读取错误直接拒绝当前压缩，不静默改变选择；旧严格模式环境变量与状态命令退出日常使用流程。
- 补充中英文插件展示信息与图标；DSH 最低版本提升至 0.2.2-rc.5。
- 自定义正文替换复用官方请求流程，保留按模型配置的摘要路由、token 上限与输出校验。

## 1.1.0

- 新增严格模式开关 `DSH_COMPACTION_PROMPTS_STRICT`：开启后 `active/` 没有可用文件时压缩直接报错并给出原因，不再静默使用官方指令。默认关闭，行为与 1.0.0 一致。
- `/compact-prompt` 显示当前模式，并增加“严格拒绝”计数。

## 1.0.0

首个版本。

- 用 `presets/` 与 `active/` 两个目录保存压缩摘要提示词，移动文件即切换，下一次压缩生效。
- `active/` 无可用文件时调用官方 `summarize()` 实现，行为与内置一致。
- 文件为空、超过 64 KiB、读取失败或多文件时给出确定的回退与警告。
- 新增 `/compact-prompt` 与 `/compact-prompt list`，显示当前文件、备选列表和调用统计。
- 支持 `DSH_COMPACTION_PROMPTS_DIR` 改变提示词根目录。
