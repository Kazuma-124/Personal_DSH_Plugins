# 插件操作与未读标记

给 DeepSeek Harness 的 Web 界面加两处小改动：

- 在 **插件 / Plugins** 管理器的每个插件详情页加一个 **打开所在文件夹 / Open containing folder** 动作，直接在系统文件管理器里定位该插件的安装目录。
- 在会话侧栏的行菜单里加 **标为未读 / Mark as unread**，把已经读过、但暂时没空处理的会话重新标记出来，直到再次打开它。

## 为什么需要

插件的安装位置只写在 profile 的依赖里：装了本地目录或 `link:` 时，想知道文件到底在哪儿，只能自己翻 `<profile>/node_modules`。第一个功能在详情页动作区加一个按钮，点一下就在系统文件管理器里打开该插件的安装目录。

会话列表只提示「有新完成、尚未查看」的会话；一旦打开过，提示就消失了。但「读过」不等于「处理完」：想稍后回来处理时，列表不会再提醒。第二个功能把这类会话重新标记出来，侧栏行尾保留一个未读圆点，直到再次打开该会话。

## 行为

### 打开所在文件夹

- 位置：插件详情页标题下方动作区（`plugins.detail.actions`），在页面自己的开关和卸载之前。
- 解析：Host 以 profile 的 `package.json` 为锚点解析 `<包名>/package.json`，取它所在目录；`link:` 安装会跟随到真实目录。
- 打开：Windows 用 `explorer.exe`，macOS 用 `open`，Linux 用 `xdg-open`；参数直接传给可执行文件，不经过 shell。
- 失败：内置插件（装在 `app.asar` 里）或无法解析的包，按钮下方给出说明，不会打开空路径。
- 请求体上限 8 KiB；只接受合法包名，非法请求返回 400/413/404，不会把用户输入拼进路径。

### 标为未读

- 位置：会话行的「…」菜单和右键菜单，排在置顶、重命名、分叉之后；已标记的会话显示「取消未读标记」。归档的会话不提供该项。
- 标记：写入浏览器本地存储（键 `dsh.plugin-actions.unread.v1`），会话行尾出现未读圆点，颜色与大小和宿主自己的「完成未查看」状态点一致。
- 去重：宿主已经显示「完成未查看」状态点的会话不再重复显示行尾圆点；该状态点消失后（例如会话重新开始运行），未读标记重新可见。
- 打开：会话成为主视图时清除标记。重启 DSH 时，如果被标记的会话正是恢复打开的会话，标记会保留（此时不显示圆点），离开后再打开该会话时才清除。
- 归档：归档会话的标记会被清除，与宿主不在归档行显示状态点的行为一致；取消归档后也不会恢复。
- 范围：标记是浏览器本地的查看状态，不写入会话日志、不修改 Host 数据、不跨浏览器同步；最多保存 500 个会话 id。
- 反馈：行尾圆点在指针停留在该行、键盘聚焦该行或行菜单打开时随行尾信息一起被宿主隐藏，所以标记和取消都会通过共享提示确认；浏览器存储不可写时提示「无法保存未读状态」，当前页面仍保留本次标记。

## 安装

按目录安装：

```sh
dsh plugin --profile <profile> add ./Personal_DSH_Plugins/dsh-plugin-actions
```

或在 **插件 → 添加插件** 里选中 `dsh-plugin-actions/` 目录，或添加本仓库的插件索引后在「发现」页安装。安装后打开任意插件的详情页，应能看到「打开所在文件夹」；在会话侧栏的「…」菜单里应能看到「标为未读」。

当前版本 `1.1.0`，各版本变化见 [CHANGELOG.md](CHANGELOG.md)。

## 开发

```powershell
node --test dsh-plugin-actions/tests/*.test.mjs
```

`tests/client.test.mjs` 用 Node 的全局 `window` 模拟浏览器存储、会话列表、Workspace 归档集合和插槽注册，覆盖标记的写入与读取、菜单标签切换、行尾圆点的显示条件、打开会话与归档时的清除、重启后保留，以及存储不可写时的提示；`tests/index.test.mjs` 覆盖 Host 路由和元数据一致性。

## 已知限制

- 「打开所在文件夹」只覆盖插件详情页；插件列表卡片上没有按钮，因为 DSH 的插件页目前只声明了详情页动作槽位（`plugins.detail.actions`），没有卡片级槽位。
- 内置插件位于 `app.asar`，文件管理器无法打开归档内路径，因此不提供该动作。
- 未读标记只影响侧栏的会话行；行尾圆点会随行尾信息在悬停、键盘聚焦或菜单打开时隐藏，此时只能从行菜单的「取消未读标记」确认状态。标记保存在当前浏览器，换浏览器或清除站点数据后不再保留；它不会出现在其他设备上。
